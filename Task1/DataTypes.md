## Риски для каждого типа данных:
### 1. Данные по объектам недвижимости:
  + **устаревание данных (незначительный)** - параметры объекта могут измениться
    + неудобство использования приложения
    + пользовательское раздражение
    + потеря доверия клиентов
    
  + **искажение данных (незначительный)** - могут быть изменены параметры объекта в результате атаки на приложение
      + неудобство использования приложения
      + пользовательское раздражение
      + потеря доверия клиентов
    
 + **некачественные данные (незначительный)**
     + неудобство использования приложения
     + пользовательское раздражение
     + потеря доверия клиентов

### 2. Данные клиента
 + **устаревание данных (значительный)** - могут меняться, по естественным причинам паспортные данные, данные карт, расчетных счетов и т.д.)
   + недовольство пользователей
   + трудности в предоставлении качественных, своевременных услуг
   + проблемы с взаиморасчетами, риски просрочек платежей
   
 + **потеря данных (критический)**
   + недовольство пользователей
   + в случае потери данных о пользователе могут возникнуть проблемы с взаиморасчетами
   + потеря доверия клиентов
   + финансовые потери
   + утрата конкурентных возможностей

 + **искажение данных (значительный - критический)**
   + в зависимости от того какие данные были искажены будет и степень риска.
   Последствия могут быть как взаиморасчетами так и с идентификацией пользователя

### 3. Профиль клиента
+ **потеря данных (критический)**
    + недополучение прибыли
    + финансовые потери
    + потеря имиджа (если станет известно общественности)
  
+ **искажение данных (значительный - критический)** 
 + недополучение прибыли
    + финансовые потери
    + проблемы с предоставлением услуг
    + недовольство пользователей
    + сложности с предоставлением специальных предложений клиентам
    
+ **утечка данных (критический)** - в этом случае пользовательские данные и данные о его предпочтениях и финансовой стабильности попадут в руки третьих лиц
  + потеря имиджа (если станет известно общественности)
  + проблемы с безопасностью авторизацией и аутентификацией
  + потеря доверия клиентов (если станет известно общественности)

+ **некачественные данные (значительный)** - в этом случае из-за сбоя или ошибки в работе приложения часть данных собрана неправильно или стала недоступна дли использования
  + недовольство пользователей
  + недополучение прибыли
  + трудности в предоставлении качественных, своевременных услуг
  + сложности с предоставлением специальных предложений клиентам

### 4. данные для аутентификации:
 здесь риски:
 + потеря данных
 + искажение данных
 + некачественные данные

**значительные** ведут к одним и тем же проблемам:
 + Проблемы с безопасностью авторизацией и аутентификацией
 + недополучение прибыли
 + недовольство пользователей

**риск: утечка данных (критический)** т.е. данные для авторизации и аутентификации попали в третьи руки
вречет за собой, помимо выше-указанных рисков добавляют риски:
+ финансовые потери
+ потеря имиджа
+ утрата, искажение пользовательских данных и профиля пользователя
+ утечка других данных приложения в руки третьих лиц

### 5. бизнес-аналитика:
- **утечка данных (критический - значительный)**

  - **Критический** - если, в руки третьих лиц, попали данные:
    + коммерческой тайны
    + данные клиентов
    + планы по расширению, детали договоров с будущими клиентами
    + инвестиционные планы
  - **Значительный** - если утекли:
    + обезличенные данные
    + данные не содержащие коммерческой тайны
  
    **Последствия утечки данных:**
      + финансовые потери
      + недополучение прибыли
      + утрата конкурентного преимущества
      + намечающиеся сделки могут перехватить
      + потеря имиджа

- **потеря данных (критический), искажение данных(критический), некачественные данные(критический)**,
  - недополучение прибыли
  - утрата конкурентного преимущества
  - ошибки в стратегии развития компании
  - ошибки в оценках будущей прибыли, прогнозировании финансовых потоков


- **обесценивание данных (значительный)** - т.е. потеря их актуальности, влечет за собой:
    - утрата конкурентного преимущества
    - потерю времени на разработку стратегии
    - недополучение прибыли
    - отставание компании в развитии

### 6. финансовые данные:
- **утечка данных (критический)**,
  + может привести к искажению других типов данных
  + недовольство клиентов
  + имиджевые потери
  + финансовые потери
  + штрафы от государства
  + уголовная ответственность для работников или руководства
  + потеря инвестиционной привлекательности

- **потеря данных (критический)**,
  - утрата контроля за финансовыми потоками компании
  - искажение данных бизнес-аналитики
  - имиджевые потери (если станет известно общественности)
  - штрафы от государства
  - потеря инвестиционной привлекательности

- **искажение данных (критический)**,
    - утрата контроля за финансовыми потоками компании
    - искажение данных бизнес-аналитики
    - проблемы с финансовой отчетностью
    - штрафы от государства

### 7. Данные о подрядчиках:
- **утечка данных (значительный-критический)**,
- **потеря данных (значительный-критический)**,
- **искажение данных (значительный-критический)**

**Обоснование**: данные о подрядчиках могут содержать коммерческую тайну, сведения о гос. закупках, взаиморасчетах, реквизиты
Любой из рисков, указанных выше, влечет за собой возможные последствия:
+ проблемы с взаиморасчетами
+ утрата доверия со стороны подрядчиков
+ судебные разбирательства
+ штрафы
+ финансовые потери
+ потеря выгодных договоров, задержки поставок - это влечет недополучение прибыли
+ искажение данных для бизнес-аналитики

### 8. Данные о работах на объекте:
Здесь риски тоже могут варьироваться от **значительных до критических**

Данные подвержены рискам:
- **утечка данных**,
- **потеря данных**,
- **искажение данных**,
- **некачественные данные**

**Если реализовался, один из указанных рисков**, для данных:
+ о ходе работ
+ о применяемых материалах (без цен)
+ о поставщиках
+ о подрядчиках (только их публичные данные)
+ о сроках работ
+ об ожидаемых результатах

в этом случае риск: **значительный** и может повлечь за собой
- утрату доверия подрядчиков
- имиджевые потери
- недополучение прибыли
- недовольство пользователей

**Если реализовался один из рисков**, указанных выше, для данных:
+ содержащих коммерческую тайну
+ информацию о закупках с ценами
+ информацию о работах с ценами
+ детали договоров
+ о нарушениях во время строительства
+ о растратах или превышении сметы

в этом случае риск: **критический** и может повлечь за собой:
+ штрафы от государства
+ судебные разбирательства
+ конфликты с поставщиками и подрядчиками
+ уголовную ответственность
+ снижение или утрату инвестиционной привлекательности
+ финансовые потери

## 9. данные об операциях с недвижимостью
Данные относящиеся к гос. тайне

Подвержены рискам:
- **утечка данных (критический)**,
- **потеря данных (критический)**,
- **искажение данных (критический)**

Если, по вине компании, реализуется любой из указанных рисков, то это может повлечь за собой:
+ штрафы
+ судебные разбирательства
+ уголовную ответственность
+ санкции в отношении компании (запрет на некоторые виды деятельности)

## 10. Данные о компании
 + **Публичные данные компании**

    - **некачественные данные(незначительный)**

  - недовольство пользователей
  - незначительные имиджевые потери

    - **утечка данных (критический)**,

    - **искажение данных(критический)**
    - **некачественные данные(критический)**

**Обоснование**: реализация, вышеуказанных рисков, для этих типов данных, может, повлечь за собой:
+ штрафы от государства
+ финансовые потери
+ риски мошеннических действий
+ угроза искажения других типов данных в приложении

## 11. Данные необходимые для управления "умным домом"
Подвержены рискам:
  - **утечка данных (критический)**,
  - **потеря данных (критический)**,
  - **искажение данных (критический)**,
  - **некачественные данные (критический)**

**Обоснование**: реализация, вышеуказанных рисков, для этих типов данных, может, повлечь за собой:
 - взлом дома (открытие замков, отключение системы безопасности)
 - получение данных с телефона, камер (т.е. риски утечки приватных данных пользователей)

**Последствия для компании:**
- судебные иски
- штрафы
- финансовые потери
- имиджевые потери
- утрата конкурентного преимущества
- снижение или утрата инвест. привлекательности
